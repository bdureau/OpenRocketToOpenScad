ORKtoSCAD

Руководство пользователя · версия {{version}}

ORKtoSCAD превращает ракету, спроектированную в OpenRocket (файл .ork), в файлы для изготовления её деталей: 3D-модели для печати, чертежи для лазерной или фрезерной (ЧПУ) резки и модели OpenSCAD, которые можно изменять.

1Что создаёт ORKtoSCAD

Каждый компонент проекта даёт один или несколько файлов, все размеры в миллиметрах:

Компонент OpenRocketSTL (3D-печать)SVG (лазер / ЧПУ)OpenSCAD
Головной обтекатель, переходник✓–✓
Труба корпуса, соединительная муфта, внутренняя труба, упор двигателя✓–✓
Центрирующее кольцо✓✓✓
Перегородка–✓✓
Трапециевидные, эллиптические стабилизаторы и стабилизаторы произвольной формы (один стабилизатор с шипом)–✓✓
Трубчатые стабилизаторы, направляющая трубка, направляющий ролик✓–✓

Детали в подвесных блоках и ускорителях обрабатываются так же. Парашюты, тормозные ленты, амортизирующие шнуры и грузы — не детали для печати или резки: они пропускаются, а отчёт сообщает их количество.

2Установка и запуск

  • Приложение для Windows: откройте папку ORKtoSCAD и запустите ORKtoSCAD.exe (или ярлык в меню «Пуск», если вы использовали установщик). Не разделяйте папку: в ней своя Java, поэтому устанавливать Java не нужно.
  • Версия для Java (Windows, macOS, Linux): если установлена Java 16 или новее, дважды щёлкните orkToScad.jar или введите java -jar orkToScad.jar. Файл .ork, указанный после команды, будет сразу преобразован.
  • OpenSCAD (необязательно, бесплатно, openscad.org) нужен только для вкладки Рендер и для изменения или экспорта файлов .scad. Файлы STL и SVG создаются без него.

3Окно программы

  1. 1Меню Справка: это руководство (F1) и сведения о программе.
  2. 2Файл OpenRocket для преобразования. Введите путь, нажмите Обзор… или перетащите файл на окно.
  3. 3Папка вывода. Предлагается папка <проект>_out рядом с файлом .ork; кнопка Обзор… позволяет выбрать другую.
  4. 4STL и SVG: также записывать 3D-файлы и чертежи для резки. Файлы .scad записываются всегда.
  5. 5Преобразовать запускает преобразование.
  6. 6Открыть папку… показывает файлы прежнего преобразования без повторного преобразования.
  7. 7Язык программы (см. раздел 8).
  8. 8Детали, сгруппированные по видам, с доступными файлами (STL, SVG, SCAD) и числом экземпляров для изготовления (× 2…). Поле вверху фильтрует список по названию.
  9. 93D-вид выбранной детали (файл STL).
  10. 102D-чертёж выбранной детали (файл SVG).
  11. 11Код OpenSCAD детали или её рендер в OpenSCAD.
  12. 12Результат последнего преобразования. Показать отчёт выводит подробности.

4Преобразование проекта

  1. Сохраните проект в OpenRocket. Читаются файлы всех современных версий, сжатые и несжатые.
  2. Выберите файл .ork кнопкой Обзор… или просто перетащите его на окно: тогда преобразование начнётся сразу.
  3. Проверьте папку вывода и отметьте STL и/или SVG.
  4. Нажмите Преобразовать. Строка состояния покажет число записанных файлов, предупреждений и примечаний, а детали появятся в списке.
  5. Нажмите Показать отчёт, чтобы прочитать список файлов, предупреждения (например, деталь пропущена из-за отсутствующего размера) и примечания (число экземпляров для изготовления, компоненты, которые не создаются).
Файлы с теми же именами, уже лежащие в папке вывода, будут заменены.

5Файлы

  • Имена: вид детали и номер в порядке проекта, например body-tube-3d1.stl, centeringring-CNC1.svg, noseCone-Ogive3D.scad. 3d обозначает объёмную деталь, CNC — плоский контур для резки.
  • .scad: модель детали в OpenSCAD — открывайте, изменяйте или экспортируйте её в OpenSCAD.
  • .stl: та же деталь, что в файле .scad, готовая для слайсера. Задний торец внизу (z = 0), вершина вверху; хвостовики включены и соединены со стенкой.
  • .svg: контур резки в натуральную величину тонкой красной линией (0,1 мм) без заливки: один замкнутый контур для стабилизатора с шипом, концентрические окружности для кольца или перегородки.
  • Сколько: на каждую деталь записывается один файл. Если деталь нужна несколько раз (число стабилизаторов, подвесные блоки, несколько направляющих роликов), список показывает × n, а отчёт — сколько изготовить.
  • Размеры «auto»: размеры, оставленные в OpenRocket как auto (радиус трубы, кольца…), рассчитываются так же, как в OpenRocket.

6Просмотр деталей

Щёлкните деталь в списке: её файлы появятся в трёх панелях.

3D-вид

Перетаскивайте, чтобы вращать, колесом мыши — масштаб, перетаскивание правой кнопкой — сдвиг, двойной щелчок возвращает исходный вид (Исходный вид). Разрез разрезает деталь пополам и показывает толщину стенок; внутренние поверхности синие. Вверху указаны размеры детали и число треугольников.

2D-чертёж

Линия реза нарисована красным на миллиметровой сетке (Сетка мм) с диаметрами окружностей или размерами контура и масштабной линейкой. Вписать показывает деталь целиком; колесо мыши меняет масштаб.

OpenSCAD

Код показывает цветной код с номерами строк. Если у детали несколько файлов .scad (у центрирующего кольца есть 2D- и 3D-файл), выберите нужный в списке рядом с вкладками. Рендер показывает деталь, рассчитанную OpenSCAD (это может занять несколько секунд). Открыть в OpenSCAD открывает файл программой, связанной с файлами .scad.

Если OpenSCAD установлен, но не найден, нажмите внизу панели Указать, где он установлен… и выберите openscad.exe. Выбор запоминается.

7Изготовление деталей

3D-печать

  • Откройте файлы .stl в слайсере (PrusaSlicer, Cura, Bambu Studio…); единица измерения — миллиметр.
  • Длинные трубы корпуса записываются одним куском: разрежьте их в слайсере, если они не помещаются в принтер.
  • Отверстие под винт в направляющих роликах не моделируется: просверлите его или добавьте в OpenSCAD.

Лазерная резка или ЧПУ

  • Файлы SVG имеют размеры в миллиметрах и импортируются в натуральную величину в LightBurn, Inkscape, LaserGRBL… Проверьте, что программа не меняет масштаб при импорте.
  • Компенсация ширины реза не применяется: задайте её в программе лазера или САМ.
  • Стабилизаторы: один стабилизатор в файле, корневая хорда внизу вместе с шипом; вырежьте указанное число стабилизаторов (× n).

8Язык

Программа запускается на языке компьютера, если это один из 11 доступных языков, иначе — на английском. Выберите другой язык в списке справа вверху: окно сразу сменит язык и сохранит загруженные детали. Автоматически возвращает язык компьютера. Выбор запоминается.

9Если что-то не так

  • Не хватает детали: прочитайте предупреждения в отчёте. Компонент с размером auto, который не из чего вывести, пропускается: задайте ему размер в OpenRocket и преобразуйте снова.
  • «OpenSCAD не найден»: установите OpenSCAD или укажите, где он находится (раздел 6). Код виден всегда.
  • Нет STL или SVG для детали: у плоских деталей нет STL, у объёмных нет SVG; в остальных случаях отметьте параметр и преобразуйте снова.
  • Руководство не открывается: должна быть установлена программа для просмотра PDF.
