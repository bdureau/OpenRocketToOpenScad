ORKtoSCAD

User manual · version {{version}}

ORKtoSCAD turns a rocket designed with OpenRocket (.ork file) into files you can use to make its parts: 3D models to print, plans to cut with a laser or a CNC machine, and OpenSCAD models you can modify.

1What ORKtoSCAD makes

Each component of the design gives one or more files, all dimensioned in millimetres:

OpenRocket componentSTL (3D print)SVG (laser / CNC)OpenSCAD
Nose cone, transition✓–✓
Body tube, tube coupler, inner tube, engine block✓–✓
Centering ring✓✓✓
Bulkhead–✓✓
Trapezoidal, elliptical and free-form fins (one fin with its tab)–✓✓
Tube fins, launch lug, rail button✓–✓

Parts inside pods and boosters are made in the same way. Parachutes, streamers, shock cords and mass components are not parts to print or cut: they are skipped, and the report says how many.

2Installing and starting

  • Windows application: open the ORKtoSCAD folder and start ORKtoSCAD.exe (or use the Start menu shortcut if you used the installer). Keep the whole folder together: it contains its own Java, so Java does not need to be installed.
  • Java version (Windows, macOS, Linux): with Java 16 or newer installed, double-click orkToScad.jar, or type java -jar orkToScad.jar. You can add a .ork file after it to convert it right away.
  • OpenSCAD (optional, free, openscad.org) is only needed for the Render tab and to modify or export the .scad files. STL and SVG files are written without it.

  9. 93D view of the selected part (STL file).

4Converting a design

  1. Save your design in OpenRocket. Files from all recent versions can be read, compressed or not.
  2. Choose the .ork file with Browse… — or simply drop it on the window: the conversion then starts at once.
  3. Check the output folder, and tick STL and/or SVG.
  4. Click Convert. The status bar shows the number of files written, of warnings and of notes, and the parts appear in the list.
  5. Click Show the report to read the list of files, the warnings (for example a part that was skipped because a dimension is missing) and the notes (number of copies to make, components that are not made).
Files that already exist in the output folder with the same name are replaced.

5The files

  • Names: kind of part and number in the order of the design, for example body-tube-3d1.stl, centeringring-CNC1.svg, noseCone-Ogive3D.scad. 3d marks a 3D part, CNC a flat outline to cut.
  • .scad: OpenSCAD model of the part, to open, modify or export with OpenSCAD.
  • .stl: the same part as the .scad file, ready for a slicer. The aft end is at the bottom (z = 0) and the tip at the top; shoulders are included and joined to the wall.
  • .svg: the cut outline at real size, as a thin red line (0.1 mm) without fill: one closed outline for a fin and its tab, concentric circles for a ring or a bulkhead.
  • How many: one file is written per part. When a part is needed several times (fin count, pods, several rail buttons), the list shows × n and the report says how many to make.
  • “auto” dimensions: dimensions left on auto in OpenRocket (radius of a tube, of a ring…) are worked out the same way as OpenRocket does.

6Looking at the parts

Click a part in the list: its files are shown in the three boxes.

3D view

Drag to rotate, use the wheel to zoom, drag with the right button to move, double-click to come back to the initial view (Reset view). Cutaway cuts the part in half to show the wall thickness; inner faces are drawn in blue. The size of the part and its number of triangles are shown at the top.

2D plan

The cut line is drawn in red on a millimetre grid (mm grid), with the diameters of the circles or the size of the outline, and a scale bar. Fit shows the whole part; the wheel zooms.

OpenSCAD

Code shows the coloured code with line numbers. When a part has several .scad files (a centering ring has a 2D and a 3D one), choose it in the list next to the tabs. Render shows the part as computed by OpenSCAD (this can take a few seconds). Open in OpenSCAD opens the file in the program associated with .scad files.

If OpenSCAD is installed but not found, click Tell where it is installed… at the bottom of the box and choose openscad.exe. The choice is remembered.

7Making the parts

3D printing

  • Open the .stl files in your slicer (PrusaSlicer, Cura, Bambu Studio…); the unit is the millimetre.
  • Long body tubes are written in one piece: cut them in the slicer if they do not fit on your printer.
  • The screw hole of rail buttons is not modelled: drill it, or add it in OpenSCAD.

Laser or CNC cutting

  • The SVG files are sized in millimetres and import at their real size in LightBurn, Inkscape, LaserGRBL… Check that your software does not rescale them on import.
  • No kerf compensation is applied: set it in your laser or CAM software.
  • Fins: one fin per file, root chord at the bottom with its tab; cut the number of fins shown (× n).

8Language

The program starts in the language of your computer when it is one of the 11 available languages, and in English otherwise. Use the selector at the top right to choose another one: the window changes at once and keeps the loaded parts. Automatic goes back to the language of the computer. The choice is remembered.

9If something goes wrong

  • A part is missing: read the warnings in the report. A component whose size is auto with nothing to take it from is skipped: give it a dimension in OpenRocket and convert again.
  • “OpenSCAD not found”: install OpenSCAD, or show where it is (section 6). The code is always visible.
  • No STL or SVG for a part: flat parts have no STL and 3D parts no SVG; otherwise tick the option and convert again.
  • The manual does not open: a PDF reader must be installed.

10Contact

Questions, suggestions or a design that does not convert well: write to the author, with the version number and, if possible, the .ork file.
